==================
Where results show
==================

.. list-table::
    :header-rows: 1
    :widths: 30 70

    *   -   Place
        -   What it shows
    *   -   :ref:`Report module <editor-module>`
        -   All results below a page with filters, edit, check again and
            ignore.
    *   -   :ref:`Page module <editor-page-module>`
        -   A callout with the number of broken links of the page.
    *   -   :ref:`Rich text editor <editor-page-module>`
        -   Broken links are marked in the text.
    *   -   :ref:`Mail report <mail-report>`
        -   Broken links of an area by mail, optionally as CSV.
    *   -   :ref:`Dashboard widget <dashboard-widget>`
        -   Broken links below a page by link type.

Editors and the widget see only the links they may fix, see
:ref:`permissions <permissions>`. Mail reports are not filtered per
recipient.
